# AI API 활용 기술 노트

활용한 프로젝트 
https://github.com/Gwanhoo/Capstone-Design.git

## 1. AI 기능 개요

본 프로젝트는 OpenAI API를 활용하여 프로젝트 현황을 자동으로 분석하는 AI 분석 기능을 구현하였다.

사용자가 프로젝트 보드에서 AI 분석 버튼을 클릭하면 프로젝트의 칸반 보드 정보와 메모 데이터를 수집하여 OpenAI API에 전달하고, AI가 현재 프로젝트 상태를 분석한 결과를 사용자에게 제공한다.

---

# 2. 활용 API

### OpenAI API

* 모델 : GPT 계열 모델
* 사용 목적 : 프로젝트 진행 상황 분석 및 요약
* 호출 방식 : REST API

---

# 3. AI 분석 프로세스

## Step 1. 프로젝트 데이터 수집

AI 분석 요청 시 서버는 프로젝트의 데이터를 조회한다.

수집 데이터

### 칸반 보드 정보

* 시작 전(To Do) 작업 목록
* 진행 중(In Progress) 작업 목록
* 완료(Done) 작업 목록

### 프로젝트 메모

프로젝트 참여자들이 작성한 메모 내용

---

## Step 2. 보드 스냅샷 생성

조회한 데이터를 AI가 이해하기 쉬운 형태로 변환한다.

예시

```json
{
  "todoCount": 5,
  "inProgressCount": 3,
  "doneCount": 12,
  "notes": [
    "로그인 기능 구현 완료",
    "배포 테스트 진행 예정"
  ]
}
```

---

## Step 3. OpenAI API 호출

생성된 보드 스냅샷을 Prompt와 함께 OpenAI API로 전달한다.

예시 Prompt

```text
현재 프로젝트 상태를 분석하시오.

To Do : 5개
In Progress : 3개
Done : 12개

프로젝트 메모:
- 로그인 기능 구현 완료
- 배포 테스트 진행 예정

다음을 분석하시오.

1. 프로젝트 진행률
2. 현재 진행 상황
3. 우선순위 작업
4. 잠재적 위험 요소
5. 향후 권장 작업
```

---

## Step 4. AI 응답 생성

OpenAI API는 전달받은 프로젝트 정보를 기반으로 분석 결과를 생성한다.

예시 응답

```json
{
  "progress": "60%",
  "summary": "프로젝트 핵심 기능 구현이 대부분 완료되었습니다.",
  "risks": [
    "배포 테스트가 아직 진행되지 않음"
  ],
  "nextActions": [
    "배포 환경 검증",
    "통합 테스트 수행"
  ]
}
```

---

# 4. 구현 효과

기존 프로젝트 관리 시스템은 단순히 작업 목록만 제공하였다.

본 프로젝트는 OpenAI API를 활용하여 다음 기능을 제공한다.

* 프로젝트 진행률 자동 분석
* 현재 상태 요약
* 우선순위 작업 추천
* 위험 요소 탐지
* 향후 작업 방향 제안

이를 통해 사용자는 프로젝트 현황을 빠르게 파악하고 의사결정을 지원받을 수 있다.
